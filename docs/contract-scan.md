# 合同扫描与审查

登录后从左侧导航打开「合同扫描与审查」。一次可以上传一组最多 50 张的合同照片，或一份最多 200 页的 PDF。任务总大小默认为 100 MiB，按实际上传的文件计算。照片可在提交前调整顺序和方向，也可在审查后补传单页高清照片。文件按 2 MiB 分片上传，HTTPS 下逐片校验 SHA-256。连接中断后同一分片可重传，草稿也会在审查记录中保留两小时。

浏览器以约 3000 像素长边生成照片扫描副本，小图保留实际像素，高细节补拍使用更大的处理尺寸。网页可读取的照片格式取决于浏览器解码能力。部分浏览器需要用户在手机上把 HEIC 导出成 JPEG。站内下载提供扫描副本和未改动的 PDF，手机照片仍留在相册。

数字 PDF 逐页提取文字，扫描页及含图页交给 YAML 中 `legal.ai.files.vl-provider` 对应的 OCR 模型。审查文本交给 `legal.ai.model.routes.legal`。页面提交前显示接收方名称，配置变更会暂停旧任务，待用户再次确认。风险引用经程序比对提取文字，点击引用可以预览对应页。界面分别显示识别页数和已审查页数。待核对页可以单独重试，跨页检查分批时会提示覆盖范围。OCR 和审查结果应结合原件复核。

任务、私有文件、逐页结果和队列检查点位于既有附件卷的 `contract-scans` 子目录。运行环境需保留附件卷，当前工作队列由一个后端实例管理。重新启动后从最近检查点继续。完成后默认保留 24 小时，过期立即禁止访问，删除和后台回收会清除原件、副本和报告。没有新增数据库迁移步骤。备份使用与附件卷相同的访问控制和保留策略。

试运行时一个账号可保留一个进行中的任务。全站默认同一时间处理一个任务，最多八个待处理任务。私有存储、全站每日 OCR 页数和文本审查次数可以通过 `CONTRACT_SCAN_STORAGE_BYTES`、`CONTRACT_SCAN_DAILY_OCR_PAGES` 和 `CONTRACT_SCAN_DAILY_REVIEW_CALLS` 调整。可设置 `CONTRACT_SCAN_OCR_RECIPIENT` 与 `CONTRACT_SCAN_REVIEW_RECIPIENT` 展示实际供应商名称，`CONTRACT_SCAN_ENABLED=false` 暂停提交和处理。敏感合同只用于其所属的私有任务，测试使用合成材料。
