# 提交与推送隐私检查

项目规则见根目录 `AGENTS.md`。当前检查使用固定版本 Gitleaks 8.30.1 的内置密钥规则，并增加公网 IPv4、个人绝对路径、应用凭据和非空环境变量凭据默认值检查。Gitleaks 从官方 GitHub Release 下载，安装前核对该版本发布的 SHA-256 校验值；可执行文件只放在本地 Git 元数据目录。

## 当前克隆启用

需要 Git、Python 3.9+，首次安装需要联网：

```sh
python scripts/install_privacy_guard.py
git config --get core.hooksPath
```

第二条应输出 `.githooks`。每个新克隆都必须安装；仓库文件不会自动启用 Git 钩子。安装器遇到已有自定义钩子时停止，避免覆盖原有检查。

## 检查范围

- `python scripts/privacy_guard.py staged`：读取暂存区中新增、修改、复制、重命名文件的完整暂存内容，不使用工作区副本，文件名也接受检查。压缩包直接拦截，避免打包后的密钥绕过文本扫描。
- `pre-commit`：自动执行上述检查。任何命中或工具错误均以非零退出码阻止提交。
- `pre-push`：读取 Git 提供的每个引用变更，扫描远端旧提交到本地新提交的全部新增历史；新引用扫描完整可达历史。已删除的泄露和合并提交也在范围内。无法解析远端旧对象时停止，先同步远端对象再重试。
- `python scripts/privacy_guard.py history`：只读审计当前 HEAD 的全部可达历史，不提交、不推送、不改写历史。

报告只输出文件、行号和规则，不回显密钥、源码片段或扫描器原始日志。不使用基线、不读取 `.gitleaksignore`、不接受行内 `gitleaks:allow`。

## 修复与边界

真实配置写进被忽略的 `.env` 或服务器私有配置；仓库保留 `${ENV_NAME}`、`${ENV_NAME:}` 或明确的 `your_...` / `replace_...` 占位符。不要在环境变量引用里嵌入真实默认密码。修改后重新暂存并扫描。已进入历史的凭据先撤销/轮换；仅删除当前文件不能清除历史，改写共享历史须单独授权。

姓名、真实咨询记录、证件号码、联系方式、图片、录屏及其他业务数据还须人工审查。正则扫描无法保证识别全部隐私，也无法对图片进行 OCR。源码中的公网 IP 和个人路径即使命中不属于密码，也应改成文档保留地址或通用占位符。

本地 Git 钩子可被机器所有者绕过；项目规则禁止绕过，但这不等同于 GitHub 服务端强制策略。GitHub 分支保护或推送保护需在远端另外配置，本次未修改远端设置。

无需在扫描时读取 SSH 私钥、凭据管理器或连接业务服务器。不要把密钥或未脱敏报告放进本目录。
